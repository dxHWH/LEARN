========== E7 比较器写成 <= （违反严格弱序）==========
  (a) libstdc++ 式无哨兵插排 + <=：越界读 336 次；排序后数组里出现了 7 个从未出现过的 9；左侧内存被改成 [0,5,5,5,5,5,5,5]
      同一段代码改用 < ：越界读 0 次，左侧内存 buf[1]=9（未被改写）
  (b) MSVC std::sort + <=（2000 个相等元素，Release）：比较 14635 次，访问哨兵区 0 次，哨兵被改写 0 个，耗时 0.021 ms
      同样数据用 < ：比较 4006 次
      （另：MSVC Debug 版 _DEBUG_LT_PRED 会对 pred(a,b)&&pred(b,a) 直接断言 "invalid comparator"）
