==================== E3 interval 追赶语义 (interval=0.1s, 一帧 dt=0.6s) ====================
isChase=true  卡顿帧触发 5 次，intervalElapsed=0；下一帧(16ms)再触发 0 次
isChase=false 卡顿帧触发 1 次，intervalElapsed=0；下一帧(16ms)再触发 0 次
isChase=true  dt=0.35s 触发 3 次，余量 intervalElapsed=0.0500000045（相位被保留）
isChase=true  dt=0.5s 触发 5 次，余量=1.49011612e-08（float 0.5-5*0.1 不精确为 0）
Loop(duration=0.1) 卡顿 0.35s 后各帧 onComplete 次数：1 1 1 0 1 0 → 每帧至多 1 次但不丢弃，欠账分摊到后续帧（与 interval 的封顶+清零语义不一致）
Loop(duration=0) 5 帧触发 5 次 → 每帧必触发，没有参数校验

==================== E4 回调重入安全性 ====================
A=(0,0) B=(1,0) 回调序列：A.complete C=(0,1) 
→ B 的旧句柄被 generation 拦截；C 复用 slot0 但代数为 1，旧句柄无法访问它
创建顺序 1,2,3,0(重建) 的同帧到期回调顺序：0 1 2 3 

==================== E5 测试用例的顺序依赖 (FIFO free list) ====================
free list 预留 0 个槽：h1=(0,0) h2=(0,1) → GenerationIncrement PASS, IndexReuse PASS
free list 预留 1 个槽：h1=(0,1) h2=(0,2) → GenerationIncrement PASS, IndexReuse PASS
free list 预留 2 个槽：h1=(0,1) h2=(1,1) → GenerationIncrement FAIL, IndexReuse FAIL

==================== E6 generation 溢出估算 ====================

同一 slot 每秒复用     60 次 → 829 天后 generation 回到同一值
同一 slot 每秒复用   1000 次 → 49.7 天后 generation 回到同一值

==================== E7 EventSystem 双缓冲 / 溢出 / 快照 / 异常 ====================
(a) A↔B 互相触发，5 帧派发序列：| A | B | A | B | A  最大调用深度=1
(b) 单帧 Trigger 2001 次 → 派发 2000 次，静默丢弃 1 次（无日志、无返回值）
(c) 已注销的监听者在下一帧仍被调用 1 次（快照语义；若监听者是已销毁的 UI → MissingReferenceException）
(d) 派发序列 |F1: E1 (异常逃出 Update) |F2: E4 |F3: E2 E3 → E2/E3 晚 2 帧且排到 E4 之后（乱序）
(e) 先 Trigger Appearance 后 Trigger Logic：|F1: Logic Appearance |F2: Appearance 

==================== E8 ObjectPool 陈旧 PoolObject 拷贝 ====================
a.index=3 b.index=3；Recycle(a)=true，随后 Recycle(旧拷贝)=true → b 手里的对象 inUse=false（被别人回收了）
default(PoolObject).index=0 → 若 slot0 正在使用，Recycle(default) 会解引用 null elem（C# 中为 NullReferenceException）

==================== E9 World 倒序遍历 + Tick 中注销更低下标的 Actor ====================
各 Actor 本帧 Tick 次数：A0=1 A1=0 A2=1 A3=2 A4=1 
→ 删除自己/已遍历元素安全；删除更低下标元素会让当前 Actor 被 Tick 两次

==================== E12 Unity 帧时长上限对 interval / loop 的影响 ====================
真实卡顿 0.6s，scaled   计时器(interval=0.1, chase)：本帧 dt=0.3333333 触发 3 次，余量=0.03333332
真实卡顿 0.6s，unscaled 计时器(interval=0.1, chase)：本帧 dt=0.6 触发 5 次，余量=0
真实卡顿 2.0s，scaled   计时器(interval=0.1, chase)：本帧 dt=0.3333333 触发 3 次，余量=0.03333332
真实卡顿 2.0s，unscaled 计时器(interval=0.1, chase)：本帧 dt=2 触发 5 次，余量=0
unscaled Loop(duration=0.1)：卡顿帧(2s) + 之后 30 帧(16ms) 每帧触发次数：[1] 111111111111111111111100010000
→ 总时长 2.480s，理想触发 24 次，实际 24 次；卡顿后连续约 26 帧每帧补 1 次（每帧至多 1 次，欠账分摊）
