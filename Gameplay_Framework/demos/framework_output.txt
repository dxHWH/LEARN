==================== F3 Possess / UnPossess：调用顺序与双向引用不变式 ====================

P1 C 已控制 P1，再 Possess(P2)：回调顺序
    C.Possess(P2) 开始
    C.UnPossess(P1) 开始
      P1.OnUnPossess()（此时 Controller 仍=C）
    P1.Controller=null
      C.OnUnPossess(P1)（重新读取 ControlledPawn 字段）
    C.ControlledPawn=null
    P2.PossessedBy(C) → P2.Controller=C
      P2.OnPossess(C)
    C.ControlledPawn=P2
      C.OnPossess(P2)
  状态：C→P2  P1←null  P2←C  
  ✓ 双向引用一致

P2 C1 控制 P，C2.Possess(P)（夺舍：踢掉原灵魂）
    C2.Possess(P) 开始
    C1.UnPossess(P) 开始
      P.OnUnPossess()（此时 Controller 仍=C1）
    P.Controller=null
      C1.OnUnPossess(P)（重新读取 ControlledPawn 字段）
    C1.ControlledPawn=null
    P.PossessedBy(C2) → P.Controller=C2
      P.OnPossess(C2)
    C2.ControlledPawn=P
      C2.OnPossess(P)
  状态：C1→null  C2→P  P←C2  
  ✓ 双向引用一致

P3 Pawn.OnPossess 抛异常（Possess 早于 BeginPlay，像 MyHeroPawn 那样在 BeginPlay 里取 Renderer）
    C.Possess(P) 开始
    P.PossessedBy(C) → P.Controller=C
      P.OnPossess(C)
    !! 异常冒出 Possess：NullReferenceException：_renderer 在 BeginPlay 里才赋值
  状态：C→null  P←C  
  ✗ C.ControlledPawn!=P 但 P.Controller==C

P3' 下一帧（BeginPlay 之后）重试 C.Possess(P)
    C.Possess(P) 开始
    C.UnPossess()：不存在控制的对象 → return
    P.PossessedBy(C) → P.Controller=C
      P.OnPossess(C)
    C.ControlledPawn=P
      C.OnPossess(P)
  状态：C→P  P←C  
  ✓ 双向引用一致

P4【构造反例】Seat.OnPossess 里调用 C.Possess(Car)（坐上座位立即转控载具）
    C.Possess(Seat) 开始
    Seat.PossessedBy(C) → Seat.Controller=C
      Seat.OnPossess(C)
    C.Possess(Car) 开始
    Car.PossessedBy(C) → Car.Controller=C
      Car.OnPossess(C)
    C.ControlledPawn=Car
      C.OnPossess(Car)
    C.ControlledPawn=Seat
      C.OnPossess(Seat)
  状态：C→Seat  Seat←C  Car←C  
  ✗ C.ControlledPawn!=Car 但 Car.Controller==C

P5【构造反例】Body.OnUnPossess 里调用 C.Possess(Home)（离魂时送回大本营）
    C.UnPossess(Body) 开始
      Body.OnUnPossess()（此时 Controller 仍=C）
    C.Possess(Home) 开始
    C.UnPossess(Body) 开始
      Body.OnUnPossess()（此时 Controller 仍=C）
    Body.Controller=null
      C.OnUnPossess(Body)（重新读取 ControlledPawn 字段）
    C.ControlledPawn=null
    Home.PossessedBy(C) → Home.Controller=C
      Home.OnPossess(C)
    C.ControlledPawn=Home
      C.OnPossess(Home)
    Body.Controller=null
      C.OnUnPossess(Home)（重新读取 ControlledPawn 字段）
    C.ControlledPawn=null
  状态：C→null  Body←null  Home←C  
  ✗ C.ControlledPawn!=Home 但 Home.Controller==C
  Controller.OnUnPossess 被调用 2 次（期望 1 次）

P6 Old 被直接 Destroy（没有先 UnPossess），之后 C.Possess(New)
    C.Possess(New) 开始
    New.PossessedBy(C) → New.Controller=C
      New.OnPossess(C)
    C.ControlledPawn=New
      C.OnPossess(New)
  状态：C→New  Old←C  New←C  
  ✗ C.ControlledPawn!=Old 但 Old.Controller==C
  Old.OnUnPossess 执行次数 = 0（它的清理逻辑——停寿命计时器、改名、关碰撞——永远不会执行）

==================== F4 场景里放了两个 SurvivalGameMode（“将忽略后注册的裁判”是否成立） ====================

  World.RegisterGameState：注册 GameState_GM_A
  GameState_GM_A：EnteringMap → WaitingToStart → EventSystem.Trigger
  GameState_GM_A：WaitingToStart → InProgress → EventSystem.Trigger

  CreateTimer("AISpawner")：新建

  GameState_GM_B：EnteringMap → WaitingToStart（这个 GameState 已被 World 拒绝并 Destroy，帧末才消失） → EventSystem.Trigger
  GameState_GM_B：WaitingToStart → InProgress（这个 GameState 已被 World 拒绝并 Destroy，帧末才消失） → EventSystem.Trigger
  生成玩家肉体 + SoulPlayerController 并 Possess
  CreateTimer("AISpawner")：同名计时器仍有效 → 先 Stop 旧的（属于 GM_A）再新建

  MatchStateChanged 的 Trigger 次数 = 4（其中来自被拒绝的 GameState = 2）
  玩家肉体 = 2，SoulPlayerController = 2（两个 Controller 读同一份输入 → 两具肉体同步移动）
  "AISpawner" 计时器 = 1 个，回调属于 GM_B（不是裁判）
