==== 3. 真实堆上的 new int / new int[4] ====
  new int[4]    地址未复用： 0xCDCDCDCD 0xCDCDCDCD 0xCDCDCDCD 0xCDCDCDCD
  new int[4]()  ： 0x00000000 0x00000000 0x00000000 0x00000000
  new int[4]{9} ： 0x00000009 0x00000000 0x00000000 0x00000000

==== 4. 大块内存：零初始化的代价 ====
  new char[256MB]            :   23.829 ms   首字节=0xCD（新页由系统清零，“看起来是 0”不代表初始化了）
  new char[256MB]()          :   26.697 ms
  new char[N]   + 覆盖写一遍 :   32.112 ms
  new char[N]() + 覆盖写一遍 :   35.931 ms
  make_unique<char[]>(N)     :   26.846 ms
  make_unique_for_overwrite  :   23.053 ms
  std::vector<char>(N)       :   26.998 ms
