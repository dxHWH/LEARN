CHAPTER 00

阅读指南：一张地图串起整条管线

先看清全貌：数据从哪里来、在哪里变形、在哪里变成像素、哪些阶段能写代码、哪些阶段只能配置。

一条主线：管线就是一条"把三维数据逐步离散化"的流水线

渲染管线的知识点看起来非常散：MVP 矩阵、齐次坐标、裁剪、光栅化、重心坐标、Mipmap、Early-Z、混合、MSAA、TBR……面试时也常被拆成一道道独立的题目来问。其实它们都在回答同一个问题：

🧭 全书主线

场景是连续的（三角形有无穷多个点），屏幕是离散的（只有 W×H 个像素）。管线要做的就是：把三维空间里的连续几何，经过一系列坐标变换压到二维屏幕上，再决定"每个像素被谁覆盖、长什么颜色、最终能不能留下来"。

每一个阶段要么在变换坐标（几何阶段），要么在采样离散化（光栅化），要么在计算颜色（像素阶段），要么在决定取舍（测试与混合）。而几乎所有的经典问题——走样、Z-Fighting、透视扭曲、Overdraw——都是"离散化"或"有限精度"带来的副作用。

读的时候遇到一个新知识点，可以问自己两句：它处在流水线的哪一站？它是为了解决哪一种"离散化/精度/性能"问题？能答上这两句，这个点就不再是孤立的一道题。

配套程序怎么跑

软件光栅化器只依赖 C++ 标准库，一个文件实现了完整的"顶点着色 → 近平面裁剪 → 透视除法 → 定点光栅化（Top-Left）→ 透视校正插值 → Early/Late-Z → 像素着色 → 混合 → MSAA Resolve"，并在每个环节插了计数器：

# MSVC（开发者命令行，或按 build_env.sh 设好 INCLUDE/LIB/PATH） $ cl /nologo /std:c++latest /EHsc /O2 /utf-8 soft_raster.cpp $ soft_raster.exe > run_output.txt # 13 组实验，约 10 秒 $ python ppm2png.py # out/*.ppm -> out/png/*.png（纯标准库）

书里出现的每一张渲染图都是这个程序输出的，构建电子书时以 base64 内嵌进 HTML，所以这本书是一个可以离线打开的单文件。

✅ 怎么用这本书准备面试

① 第一遍按顺序读，把图 0-1 能默画出来；② 每章末尾的"本章小结"背成口述版；③ 第 13 章的题目先自己答一遍再看参考答案；④ 被问到"你怎么证明"时，用书里的实测数字回答——"我自己写过一个软光栅，测过 Early-Z 从前往后画能把 PS 执行次数从 599 万降到 22 万"，比背定义有说服力得多。
