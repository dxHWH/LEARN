PART IV

游戏 AI 专题

把前面的理论落到游戏里：怎么让 Bot 像人（模仿学习、离线 RL）、怎么用自博弈训出强 Bot 并分出难度（多智能体 RL）、怎么设计奖励（塑形、课程、分层）、什么时候用搜索（MCTS / AlphaZero），最后把所有部件拼成面试大题“这个游戏的 AI 你会怎么做”。

CHAPTER 14

模仿学习、离线 RL 与拟人化

强化学习能练出超人的 Bot，但超人不等于好玩：反应零延迟、走位像机器、打法单一。要“像人”，就要用人类数据。行为克隆最简单，但会因为分布漂移而误差累积；DAgger 通过让专家标注学生自己走到的状态来修正；GAIL 把模仿变成对抗训练；离线 RL 直接从对局日志里学，但要防止对数据外动作的乱估计。实际项目里最常见的是 RL 与模仿学习混合。

本章目标
  • 推出行为克隆的复合误差 $O(\epsilon T^2)$ 与 DAgger 的 $O(\epsilon T)$，并用实测说明“训练集零误差 ≠ 部署时没问题”。
  • 推出 GAIL 判别器的最优解和它与 JS 散度的关系。
  • 理解离线 RL 的外推误差，以及 BCQ / CQL 两类解决思路。
  • 能设计一套“RL + 模仿学习”的拟人化方案，并说清怎么评估拟人度。
30 秒面试版答案

行为克隆（BC）把专家数据当监督学习：$\min\E_{(s,a)\sim\mathcal D}[-\log\pi(a\mid s)]$。问题是训练数据来自专家的状态分布，部署时学生一旦犯错就会走到专家没去过的状态，在那里更容易犯错，误差滚雪球，代价随回合长度平方增长 $O(\epsilon T^2)$。DAgger 让学生自己去跑，把它访问到的状态交给专家标注、并入数据集再训练，代价降到 $O(\epsilon T)$，代价是需要能随时查询的专家。GAIL 不直接拟合动作，而是训练一个判别器区分专家和策略的 (s, a)，策略用判别器给的奖励做 RL，等价于最小化两者占用度量的 JS 散度。离线 RL 只能用日志数据，难点是对数据里没出现过的动作估值不可靠（外推误差），BCQ 把动作限制在数据支持的范围内，CQL 压低数据外动作的 Q 值。游戏里做拟人化通常是 RL + 模仿混合：用人类数据做 BC 预训练，再用 RL 微调，同时加 BC 损失或对人类策略的 KL 约束，按胜率等指标动态调权；评估上要同时看行为分布匹配、多样性、强度，并做人工图灵测试。

14.1 行为克隆与复合误差

行为克隆就是监督学习：收集专家（高分玩家、策划手操）的 $(s,a)$ 对，训练 $\pi_\theta(a\mid s)$ 最大化似然。它简单、稳定、不需要奖励函数，是游戏里做拟人 Bot 的第一步。但监督学习的 i.i.d. 假设在这里不成立：

14.2 DAgger：让专家标注学生走到的状态

DAgger（Dataset Aggregation，Ross et al., 2011）的思路很直接：既然问题出在“训练分布 ≠ 部署分布”，那就到部署分布上去收集数据。每一轮用当前学生（早期混入一部分专家）去跑，把学生访问到的每个状态都请专家给出“这里应该怎么做”，并入数据集重新训练。理论上它把模仿学习化归为一个在线学习问题，保证误差只线性增长。

这张表是本章最重要的实测：

  1. BC 的训练集错误率始终为 0，但部署时有约 9% 的步骤和专家不一致。干净示范永远走同一条路，只覆盖 [[ch14.e2.rows.0.bccov|.0f]] 个格子；一旦滑步离开这条路，学生就只能乱走。再多的同类数据也没用——数据量不是瓶颈，数据分布才是。
  2. DAgger 的数据来自学生自己的分布，覆盖的格子随标注增加（800 个标注时 [[ch14.e2.rows.5.dgcov|.0f]] 格），不一致率降到 [[ch14.e2.rows.5.dgd|.3f]]。
  3. 示范时注入噪声（让专家在扰动下示范，DART，Laskey et al., 2017）也能扩大覆盖、效果接近 DAgger，而且不需要在线查询专家。游戏里请高手在“带随机干扰的对局”里示范，或者对录像做状态扰动增强，就是这个思路。
面试注意：DAgger 在游戏里的落地难点

DAgger 需要一个能随时被查询的专家。人类玩家不可能逐帧标注 Bot 走到的状态，所以在游戏里常见的替代是：① 用一个强的 RL Bot 或基于规则 / 搜索的 AI 当专家，去蒸馏一个更轻量或更像人的学生（策略蒸馏）；② 请人类在关键状态（Bot 卡住、明显出错的回放片段）上做稀疏标注；③ 用噪声示范 / 数据增强近似 DAgger 的覆盖效果。

14.3 逆强化学习与 GAIL

逆强化学习（IRL）换一个角度：不学“怎么做”，而是学“专家想要什么”——找一个奖励函数，使专家策略在它下面最优，再用 RL 求解这个奖励。好处是奖励比策略更可迁移（换地图、换对手，奖励仍然适用）。最大熵 IRL（Ziebart 2008）假设专家轨迹的概率 $\propto\exp(R(\tau))$，用极大似然拟合奖励。缺点是每更新一次奖励就要解一次 RL，太贵。

GAIL（Ho & Ermon, 2016）跳过显式奖励，直接匹配占用度量 $\rho_\pi(s,a)$（策略访问 (s, a) 的频率）。它的结构和 GAN 一样：判别器 $D(s,a)$ 区分 (s, a) 来自专家还是策略，策略用 $r(s,a)=-\log(1-D(s,a))$ 作为奖励做 RL（通常用 PPO），想让判别器分不出来。

GAIL 的优点是不会累积误差（它在自己的分布上做 RL），缺点是对抗训练不稳定、需要与环境交互、样本效率低。游戏里的变体：判别器输入只用状态或状态转移（$D(s,s')$，从录像里学，不需要动作标签）；把判别器奖励和任务奖励加权（AMP，对抗运动先验，常用于物理角色动画，让动作风格像动捕数据，同时完成任务）。

14.4 离线 RL：外推误差

手里有大量玩家对局日志，能不能不和环境交互，直接学一个比日志更好的策略？这就是离线 RL。直接把 Q-learning 用在固定数据集上会出问题：目标里的 $\max_{a'}Q(s',a')$ 会查询数据里从没出现过的动作，那些 Q 值从来没有被纠正过，可能是任意大的值（函数近似下更糟，第 8 章的高估再叠加“没人纠正”）。策略于是被引向数据外的动作，部署时一塌糊涂。在迷宫上做一个最直接的演示：行为策略 80% 选专家动作、20% 选一个固定的次选动作，另外两个动作从不出现；每步奖励 −1，Q 初值为 0（demos/ch14_imitation.cpp E3）：

方法核心思想一句话
BCQ（Fujimoto 2019）策略约束用生成模型学行为策略，只在“数据里可能出现的动作”中取 max
TD3+BC（Fujimoto 2021）策略约束actor 损失 = $-\lambda Q(s,\pi(s))+(\pi(s)-a)^2$，加一项 BC 就够
CQL（Kumar 2020）价值保守额外最小化 $\E_s[\log\sum_ae^{Q(s,a)}-Q(s,a_{\text{data}})]$：压低所有动作、抬高数据里的动作，学到的 Q 是真值的下界
IQL（Kostrikov 2021）不查询数据外动作用期望分位数回归从数据内动作估计“接近 max”的价值，再加权 BC 提取策略

14.5 RL + 模仿学习：拟人化与风格化

纯 RL 强但不像人，纯模仿像人但不强、还会漂移。游戏项目里常见的组合方式：

  1. BC 预训练 + RL 微调：先用人类数据得到一个“像人的初始策略”，再用 RL 提升强度。AlphaStar 就是先用人类录像做监督学习再自博弈。问题是 RL 微调会慢慢“忘掉”人类风格。
  2. 约束不忘本：微调时加 BC 损失，或者加对人类策略 $\pi_{\text{human}}$ 的 KL 惩罚（和 RLHF 对 $\pi_{\text{ref}}$ 的 KL 完全同构）：$L=L_{\text{RL}}+w\cdot L_{\text{BC}}$ 或 $\max\E[r]-\beta\KL(\pi\Vert\pi_{\text{human}})$。
  3. 按指标动态调权：w 固定很难调——太大不够强，太小不像人。常用规则：胜率（对目标对手池）高于阈值就加大 w 让它更像人，低于阈值就减小 w 先保证强度（手撕代码中的 update_bc_weight）。
  4. 风格化 / 多风格：按风格标签筛选人类数据（激进 / 稳健 / 偏爱某英雄的玩法），分别做 BC 或条件化策略 $\pi(a\mid s,z)$；也可以对 RL 自己的高分轨迹按风格指标筛选后再做自模仿（SIL，Self-Imitation Learning），强化特定打法。奖励权重也会改变风格（第 16 章）。

14.6 拟人化怎么评估

维度指标说明

14.7 面试注意：易错说法

易错说法问题在哪更准确的说法
“BC 效果差是因为数据不够”没抓住本质是分布漂移：数据来自专家分布，部署在学生分布；同类数据再多也没用（表 14-1）

“拟人化就是加反应延迟和随机噪声”只是表面延迟和噪声让它“菜”，不一定“像”；决策层面的拟人要靠人类数据

追问树

怎么让 Bot 像人？ ├─ BC 的问题？ → 分布漂移，复合误差 O(εT²)；训练集零误差 ≠ 部署没问题 │ └─ DAgger 怎么解决？ → 学生跑、专家标、数据聚合 → O(εT)；需要可查询的专家 │ └─ 游戏里没有逐帧专家怎么办？ → 强 Bot 当专家蒸馏 / 关键状态稀疏标注 / 噪声示范 ├─ GAIL 原理？ → 判别器 D* = ρE/(ρE+ρπ)，策略最小化占用度量的 JS 散度 ├─ 用玩家日志直接训练行吗？ → 离线 RL：外推误差 → BCQ（约束动作）/ CQL（保守 Q）/ IQL ├─ RL 和 IL 怎么结合？ → BC 预训练 + RL 微调 + BC 损失 / KL(π‖π_human)，按胜率动态调权 └─ 怎么评估拟人度？多风格 Bot 怎么做？ → 分布匹配 + 判别器 + 多样性 + 竞技性 + 图灵测试；风格标签筛选 / 条件策略 / 自模仿
速记卡 · 第 14 章
  • BC = 监督学习；复合误差 $\sum\epsilon(1-\epsilon)^{t-1}(T-t+1)\approx\epsilon T^2/2$。
  • DAgger：学生的状态 + 专家的标签，数据聚合 → $O(\epsilon T)$；噪声示范（DART）是离线替代。
  • GAIL：$D^*=\rho_E/(\rho_E+\rho_\pi)$，目标 = $-\log4+2\mathrm{JS}$，奖励 $-\log(1-D)$。
  • 离线 RL：外推误差；BCQ / TD3+BC 约束策略，CQL 压低 $\log\sum e^Q-Q(s,a_{\text{data}})$，IQL 不查询数据外动作。
  • 拟人化：BC 预训练 + RL 微调 + $w\cdot L_{\text{BC}}$ 或 KL 约束，按胜率调权；评估 = 自动指标 + 图灵测试。
自测 1：表 14-1 中，为什么干净示范的 BC 在 25 个标注和 800 个标注时结果完全一样？

无噪声的专家每次都走同一条最短路，25 个标注已经覆盖了这条路上的所有格子，之后的标注全是重复的。数据集“变大”了，但分布没变，学生在路外的状态上仍然一无所知。

自测 2：GAIL 中策略的奖励为什么用 −log(1−D) 而不是 log D？

两者在最优点处等价，区别在梯度：策略很差时 D ≈ 0，$\log(1-D)\approx0$ 的梯度很小（GAN 的“生成器梯度消失”问题），而 $-\log(1-D)$ 始终为正、梯度更好。另外正奖励会鼓励回合变长，负奖励鼓励早结束，要根据任务选择或做偏置修正。

自测 3：为什么说 CQL 学到的 Q 是“下界”？这对部署有什么好处？

保守项把数据外动作的 Q 往下压，使得在数据支持不足的地方，学到的价值低于真实价值。贪心策略因此倾向于选择数据里有充分证据的动作，不会被虚高的外推值骗走。代价是可能过于保守，错过数据里少见但确实更好的动作。

自测 4：BC 预训练后用 RL 微调，为什么 Bot 会逐渐“不像人”？怎么缓解？

RL 只优化回报，人类风格里与胜负无关甚至略有损失的部分（犹豫、试探、非最优走位）会被逐渐优化掉。缓解：保留 BC 损失或对人类策略的 KL 约束；按拟人度指标调权；把部分风格指标写进奖励；定期用人类数据重新校准。
